# 📋 To-Do List Fullstack - Frontend (React)

Une application de gestion de tâches moderne, développée avec React, Vite et Tailwind CSS.

## 🔗 Démo en ligne

[Cliquez ici pour essayer l'application](https://todo-fullstack-frontend-nine.vercel.app)

## ✨ Fonctionnalités

- ✅ Ajouter des tâches (avec date d'échéance)
- ✅ Supprimer des tâches (avec animation)
- ✅ Marquer les tâches comme terminées
- ✅ Modifier le texte d'une tâche (double-clic)
- ✅ Filtrer les tâches (Toutes / Actives / Terminées)
- ✅ Compteur de tâches restantes
- ✅ Gestion des erreurs (message + bouton fermer)
- ✅ Animations (apparition, survol, suppression)
- ✅ Dates de création et d'échéance
- ✅ Design responsive (mobile-friendly)

## 🛠️ Technologies utilisées

- **React 19** : Bibliothèque UI
- **Vite** : Outil de build
- **Tailwind CSS** : Framework CSS
- **Axios** : Requêtes HTTP
- **Vercel** : Déploiement
